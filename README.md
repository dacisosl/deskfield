# 바탕 필드 (DeskField)

바탕화면 위에 **연한 파스텔 배경의 필드**를 만들어 폴더와 파일을 묶어두는 Windows 데스크톱 앱.
필드마다 제목을 붙일 수 있어서 `작성중`, `2학기 자료`처럼 공간을 나눠 쓸 수 있습니다.

<!-- 화면: 파스텔 필드 7개가 바탕화면을 나눠 쓰는 모습 -->

## 왜 만들었나

바탕화면은 금방 아이콘 늪이 됩니다. 폴더를 새로 파서 넣으면 깔끔해지지만, 이번엔 두 번 열어야
보입니다. 필드는 그 중간입니다 — **파일은 그대로 두고**, 화면 위에서만 구역을 나눠 한눈에 보이게
합니다.

## 주요 기능

- **파스텔 필드** — 8가지 파스텔 색, 배경 진하기 조절. 제목은 아무 때나 눌러서 고칩니다.
- **크기 조절 자유** — 8방향 손잡이로 원하는 만큼. 8px 격자에 맞춰 정렬됩니다.
- **반응형 배치** — 필드를 좁히면 아이콘이 알아서 열 수를 줄여 다시 깔립니다. 항목이 늘면 필드
  높이가 따라 자랍니다(자동 높이, 필드별로 끌 수 있음).
- **끌어다 놓기** — 탐색기에서 폴더·파일을 필드로 끌어오면 등록됩니다. 필드끼리 옮기는 것도 드래그.
  더블클릭하면 원래 프로그램으로 열립니다.
- **바탕화면 자동 정리(버튼)** — 누르면 바탕화면을 훑어 `작성중`·`폴더`·`문서`·`이미지`처럼 묶어
  **추천안을 먼저 보여줍니다.** 이름·색을 고치고 필요 없는 그룹은 꺼둔 다음 적용합니다.
- **바탕화면은 그대로** — 필드 바깥 빈 자리는 진짜 바탕화면입니다. 원래 아이콘, 우클릭 메뉴 전부
  평소처럼 씁니다. **파일을 실제로 옮기거나 지우지 않습니다.**
- 트레이 상주, 윈도우 시작 시 자동 실행, 필드 잠금.

### 단축키

| 키 | 동작 |
| --- | --- |
| `Ctrl+Alt+D` | 편집 모드 — 빈 곳을 끌어 새 필드를 그립니다 |
| `Ctrl+Alt+H` | 필드 전체 숨기기/보이기 |

## 설치

[Releases](../../releases)에서 `DeskField-Setup-x.y.z.exe`를 받아 실행합니다.
서명이 없는 설치 파일이라 SmartScreen이 한 번 막습니다 — **추가 정보 → 실행**을 누르면 됩니다.

직접 빌드하려면 (Windows에서):

```bash
npm install
npm run icon     # 앱 아이콘 생성
npm run dist     # release/DeskField-Setup-0.1.0.exe
```

## 쓰는 흐름

1. 처음 켜면 오른쪽 아래에 작은 도구 막대만 뜹니다. 평소엔 흐릿하고, 마우스를 올리면 진해집니다.
2. **✨ 버튼**으로 바탕화면 자동 정리를 한 번 돌려 뼈대를 잡습니다. 추천안을 확인하고 적용하세요.
3. **＋ 버튼**이나 **편집 모드(✎)** 에서 빈 곳을 끌어 필드를 더 만듭니다.
4. 남은 아이콘은 탐색기나 바탕화면에서 필드로 끌어다 놓습니다.
5. 배치가 마음에 들면 **🔓 버튼**으로 잠가둡니다. 실수로 밀릴 일이 없습니다.

## 어떻게 동작하나

화면 작업 영역만 한 투명 창을 바탕화면 위에 한 장 깔고, 그 위에 필드를 그립니다.

- 창은 **포커스를 받지 않게**(`focusable: false`) 설정해서 일반 창들 아래, 바탕화면 바로 위에
  머뭅니다. 클릭해도 앞으로 튀어나오지 않습니다.
- 커서가 필드 밖에 있으면 창이 마우스를 **바탕화면으로 통과**시킵니다(`setIgnoreMouseEvents`).
  그래서 필드가 화면을 덮고 있어도 원래 아이콘을 그대로 쓸 수 있습니다. 필드 위로 들어오는 순간만
  창이 입력을 받습니다.
- 이름을 입력할 때만 잠깐 포커스를 열었다가 닫습니다.

필드 배치는 `%APPDATA%\DeskField\state.json`에 저장됩니다. 앱은 **경로만** 기억하고 파일 자체는
건드리지 않습니다. 지운 필드도 파일에는 영향이 없습니다.

## 프로젝트 구조

```
electron/
├── main.ts            # 창·트레이·단축키, 파일 시스템/아이콘/저장 IPC
└── preload.ts         # 렌더러에 열어주는 API (contextBridge)
src/
├── App.tsx            # 화면 조립, 편집 모드, 메뉴, 자동 정리 적용
├── components/
│   ├── FieldBox.tsx   # 필드 한 장 — 이동·크기조절·드롭·타일 배치
│   ├── ItemTile.tsx   # 아이콘 타일 (OS 아이콘 추출)
│   ├── ScanReview.tsx # 자동 정리 추천안 검토 화면
│   ├── SettingsPanel.tsx, Toolbar.tsx, ContextMenu.tsx
├── state/useFields.ts # 필드 상태 + 저장/복원
├── lib/
│   ├── classify.ts    # 바탕화면 항목 → 추천 그룹 (순수 함수)
│   ├── layout.ts      # 열 수·필요 높이 계산
│   ├── palette.ts     # 파스텔 8색
│   └── types.ts
scripts/               # 개발용 — 빌드, 아이콘 생성, 실동작 확인 스크립트
```

## 개발

```bash
npm run dev       # 개발 모드 (렌더러 HMR)
npm run lint      # 타입 검사
npm run build     # dist/ 빌드
```

실동작 확인 스크립트 — 실제로 앱을 띄우고 마우스를 움직여 봅니다(리눅스에서는 `xvfb-run` 필요):

```bash
node scripts/smoke.mjs          # 자동 정리 흐름 + 스크린샷
node scripts/smoke-resize.mjs   # 이동·크기조절·열 재배치
node scripts/smoke-interact.mjs # 필드 그리기·항목 이동
```

## 아직 안 되는 것

- Windows 전용입니다. macOS/Linux에서도 실행은 되지만 바탕화면 층 처리가 달라 창이 앞으로 나올 수
  있습니다.
- 모니터 여러 대를 쓰면 주 모니터에만 필드가 깔립니다.
- 실제 바탕화면 아이콘을 필드 안으로 "빨아들이지는" 않습니다. 필드는 별도 층이고, 원래 아이콘은
  그 아래 그대로 있습니다. 겹쳐 보이는 게 싫다면 바탕화면 우클릭 → 보기 → 아이콘 표시를 끄고
  필드만 쓰는 방법이 있습니다.
- 파일이 사라지면 타일이 흐리게 남습니다(자동으로 지우지 않습니다).
